# Cascade Control 0.3.1

Исправления к 0.3.0: схема трафика, правила маршрутизации и окно программы.

## Что исправлено

- **Портреты на схеме и в карточках** показывают лицо и верх фигуры, а не ноги. У «Российских сайтов» теперь иконка, а не героиня.
- **Героиня выбирается по стране и по имени узла:** Питер — Россия, Amsterdam — Нидерланды, Вена — Австрия. Больше не будет одной общей девушки у разных стран.
- **Галерея героинь** в карточке сервера: можно выбрать портрет вручную или оставить «Авто (по стране)». В галерее портрет показан на тёмном и светлом фоне. Выбор сохраняется и виден на схеме.
- **Страница «Маршрутизация»** сразу показывает правила из локальной базы и не ждёт SSH и загрузку списков.
- Правило **«Всё остальное» всегда последнее**, иначе правила ниже него не работают. Порядок чинится при обновлении; в интерфейсе ловец нельзя поднять выше остальных. Правила можно перетаскивать.
- **Дубликаты «Gemini / Google AI»** убираются при обновлении.
- В строке правила видны **действие, выход (и WARP, если он на этом выходе) и условие совпадения**.
- Окно консоли у собранной Windows-версии скрыто. Журнал пишется в `panel.log` в каталоге данных панели и ротируется. Для отладки запустите с флагом `--console`. Установщик обновлений тоже не всплывает чёрным окном.
- Исправлена ошибка `database is locked` при добавлении списка WARP: база в режиме WAL с таймаутом ожидания, списки WARP заполняются один раз при обновлении, а не при каждом открытии страницы.

## Файлы релиза

- `CascadeControl-windows-x64.zip` — Windows x64, распаковывать целиком.
- `CascadeControl-windows-x64.zip.sha256` — контрольная сумма SHA-256.
