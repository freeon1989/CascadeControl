## Cascade Control 0.2.0: обновление прямо из программы

### Что нового

- **Обновление с GitHub.** В «Настройки» → «Обновления» есть кнопка «Проверить обновления». Программа также сама смотрит последний выпуск при запуске (можно выключить). Если вышла новая версия, показывается список изменений и кнопка «Обновить».
- **Только по вашему нажатию.** Без клика ничего не скачивается и не ставится. Можно пропустить конкретную версию.
- **Безопасно.** Архив скачивается по HTTPS только с узлов GitHub и сверяется по SHA-256 с файлом `CascadeControl-windows-x64.zip.sha256` из того же релиза. Если сумма не совпала, установка не начинается.
- **С откатом.** После выхода панели маленький `CascadeUpdater.exe` меняет файлы и запускает новую версию. Если она не ответила, прежняя возвращается автоматически. Старая версия остаётся рядом в папке `CascadeControl.backup-<версия>`.
- **Данные не трогаются.** База, ключи, серверы и клиенты лежат в `%USERPROFILE%\.cascade-control`, обновление их не касается.
- **Обновление агента на входе.** Если панель новее агента на входном сервере, в «Серверах» появляется кнопка «Обновить агент». После подтверждения панель по SSH заменяет бинарник и перезапускает только службу `cascade-agent`. Если служба не поднялась, возвращается прежний бинарник. Агент теперь сообщает свою версию.
- Исправлен ответ 404 для неизвестных адресов API: теперь он всегда в UTF-8.

### Как обновиться на 0.2.0

Версия 0.1.1 не умеет обновляться сама, поэтому один раз скачайте `CascadeControl-windows-x64.zip` отсюда и распакуйте поверх старой папки (данные в профиле сохранятся). Следующие версии программа предложит сама.

После обновления откройте «Серверы»: у входа появится пометка «Обновить агент». Нажмите, когда вам удобно.

### Файлы

- `CascadeControl-windows-x64.zip` — Windows x64, распаковывать целиком (рядом с `CascadeControl.exe` должна быть папка `_internal`).
- `CascadeControl-windows-x64.zip.sha256` — контрольная сумма SHA-256.

Файл не подписан: если SmartScreen предупреждает, выберите «Подробнее» → «Выполнить в любом случае».
