Cascade Control — панель каскада VPN
=====================================

Это программа для вашего компьютера. Она открывает локальную страницу
и не слушает сеть: только 127.0.0.1, порт 47123.

Как запустить
-------------
1. Распакуйте весь каталог. Не переносите один CascadeControl.exe
   без соседних файлов: рядом лежит папка _internal.
2. Дважды щёлкните CascadeControl.exe.
3. Появится чёрное окно журнала и, если установлен Edge WebView2,
   окно панели. WebView2 на этой машине уже есть.
4. Если окно панели не открылось, в журнале будет адрес
   http://127.0.0.1:47123 — откройте его в браузере.
   Чёрное окно не закрывайте: это и есть работающая панель.

Первый запуск
-------------
База создаётся у вас в профиле: %USERPROFILE%\.cascade-control
В комплекте нет базы, ключей и паролей.

На пустой базе панель показывает учебную схему (ru-entry, tr-1,
выходы). Это демо: адреса вымышленные, подпись «демо» стоит в таблице.
Ключи для неё создаются на этом компьютере в момент первого запуска,
их нет внутри exe. Демо не является вашей боевой конфигурацией.
Удаляется кнопкой «Удалить демо-данные» в разделе «Настройки».
После этого добавьте свои серверы.

Что внутри, кроме exe
---------------------
В программу вложен бинарник агента для Linux (amd64). Это не программа
Windows. Когда вы устанавливаете входной узел, панель сама копирует
агент на сервер по SSH. Отдельно запускать его на Windows не нужно.

Данные и журнал
---------------
%USERPROFILE%\.cascade-control\cascade.db   — база
%USERPROFILE%\.cascade-control\master.key   — ключ шифрования секретов
%USERPROFILE%\.cascade-control\panel.log    — журнал запусков

Пароль SSH и приватные ключи в журнале не пишутся.
Телеметрии нет.
