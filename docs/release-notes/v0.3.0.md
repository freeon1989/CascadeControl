# Cascade Control 0.3.0

Новый дизайн панели, живая схема трафика и опции выхода. Все новые возможности выключены по умолчанию.

## Что появилось

- **Живая схема трафика** на обзоре: клиенты → вход → российские сайты напрямую (зелёная ветка) и каскад на выходы, при необходимости через Cloudflare WARP в интернет. Линии анимируются по реальному состоянию (основной, резерв, нет связи). Подписаны порты и протоколы. Нажмите узел, чтобы открыть его карточку. Рядом с каждым узлом — героиня его страны.
- **Новый вид карточек серверов.** У каждого узла героиня подбирается по стране (RU, NL, AT, DE, FI, US и запасной портрет). Есть светлая и тёмная тема.
- **Выход через Cloudflare WARP** — переключатель в карточке выходного узла.
  - «Только выбранные сайты» (по умолчанию, если включить): ChatGPT, Gemini, Google и то, что вы сами добавите. Список редактируется в «Маршрутизация → Список WARP»: домены, сети, `geosite:` и `geoip:`, с источником, датой, закреплением и исключением. После сохранения обновляется конфиг Xray на выходах.
  - «Весь трафик выхода»: на сервере ставится официальный клиент WARP, из туннеля исключаются адрес входа и (если SSH идёт напрямую) адрес панели, включается MASQUERADE на интерфейсе CloudflareWARP. Если включение не удалось, настройки откатываются, ошибка показывается по-русски.
  - Если установленный Xray умеет MASQUE, это отмечается в карточке; иначе запасной путь пропускается с пояснением.
- **SSH к выходам через входной узел** — переключатель в «Настройках». Панель ходит к транзитным и выходным серверам через вход, их хостер не видит адрес вашего компьютера. Если вход недоступен, подключение не откроется.
- **Защита выхода** (отдельные переключатели, по умолчанию выключены): блокировать торренты, закрыть доступ к локальной сети сервера (`geoip:private`), резать рекламу.
- **Российские гео-базы runetfreedom** (`geosite.dat` и `geoip.dat`) — в источниках списков, выключены, с обновлением по расписанию. Удобно для правил «российские сайты напрямую».
- **Тест маршрута** в разделе «Маршрутизация»: вводите сайт или IP и видите, через какой выход и пойдёт ли трафик через WARP.

## Как включить

1. Схема и героини видны сразу на «Обзоре» и в «Серверах». Тему можно переключить внизу меню.
2. WARP: карточка выхода → «Выход через Cloudflare WARP», затем выберите режим. Список сайтов — «Маршрутизация → Список WARP».
3. SSH через вход: «Настройки» → «SSH к выходам через входной узел».
4. Защита: те же карточки выходов, три отдельные галочки.
5. Гео-базы: «Маршрутизация → Источники», включите runetfreedom и нажмите «Обновить сейчас».
6. Тест маршрута — вверху страницы «Маршрутизация».

## На что обратить внимание

- Через WARP некоторые сайты показывают капчу или не пускают. Режим «только выбранные сайты» затрагивает меньше трафика и обычно быстрее.
- Режим «весь трафик» чуть увеличивает задержку и требует, чтобы вход (и при прямом SSH — адрес панели) были исключены из туннеля, иначе можно потерять доступ по SSH. При сбое панель сама откатывает настройки.
- Блокировка торрентов и локальной сети помогает не получить жалобу хостера, но режет и нужный трафик, если он попал под правило.
- Geodata runetfreedom нужно сначала включить и обновить; до этого категории вроде `geosite:category-ru` зависят от файлов, которые уже лежат рядом с Xray.
